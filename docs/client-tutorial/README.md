# 客户端订阅教程

从原私有仓库（SSPanel-Uim-Anankke-20200410，分支 `claude/sspanel-subscription-tutorial-5bt1rm`）迁移过来的客户端订阅教程。

| 文件 | 说明 |
| --- | --- |
| `subscription-tutorial.md` | 教程正文（Markdown） |
| `subscription-tutorial.html` | 单文件网页版（图片已内嵌），可直接放到网站上或发给用户 |
| `images/` | 教程中的面板截图 |
| `build.py` | 修改 Markdown 后重新生成网页版：`pip install markdown && python3 docs/client-tutorial/build.py` |

**注意：** 教程对应的是原私有版面板的订阅页面（sing-box、v2rayN、Clash、Surge、Shadowrocket、Loon、Quantumult X，
以及 SS2022 / VLESS 等按协议订阅）。niuniupanel 目前的订阅与 SSPanel-UIM 2020 版一致（SSR、SS / SSD、V2Ray、Clash），
用户中心页面的按钮和截图不同，直接给 niuniupanel 的用户使用前需要按实际页面调整。
客户端下载地址、选择客户端、导入步骤等通用部分可以直接沿用。
